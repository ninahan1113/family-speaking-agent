# 家庭口语 Agent

一个以成人真实工作与生活沟通为起点的 AI 英语口语教练项目。儿童英语启蒙作为后续扩展方向，不进入首版范围。

## 当前阶段

**阶段：问题与方案验证（Discovery）**

先由两位成人作为种子用户，验证以下闭环是否能带来可感知、可复测的口语提升：

`诊断 → 真实场景练习 → 最小纠错 → 间隔复练 → 跨场景复测`

## 本地 MVP

MVP 位于 [`mvp/`](mvp/)，无需安装依赖：

```bash
cd family-speaking-agent/mvp
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。它使用浏览器本地存储保存体验数据；当前是**演示教练模式**，用于验证以下新版训练流程：

- 零配置首次开口与渐进诊断；
- 每日单一训练任务；
- 可选的“带素材训练”入口；
- 会话后的最小反馈和明日重点。

MVP 现为**语音优先、移动优先**：点击“说英语”后，浏览器将语音转写并自动提交，AI 的英文回复会通过浏览器语音播放；文字输入仅作为无法使用麦克风时的备用入口。它包含 PWA 安装与离线缓存配置，适合先验证“加到手机主屏幕后是否愿意每天开口”。语音能力依赖浏览器与用户授予的麦克风权限。

正式版将改为原生移动 App，以实现可靠的连续语音、耳机/后台音频、通知和从手机分享文章、图片、录音、文档到训练的体验。

MVP 不会调用真实 LLM 或语音评估服务，因此不能把反馈当作真实诊断结论。

## 公网部署方案

正式家庭测试采用 **GitHub Pages + Supabase**：GitHub Pages 托管 HTTPS 静态前端，Supabase 以匿名用户保存跨会话训练状态。部署工作流位于 `.github/workflows/deploy-pages.yml`；数据库表结构位于 `supabase/schema.sql`。只需在 GitHub 仓库配置 `SUPABASE_URL` 与 `SUPABASE_ANON_KEY` 两个 Actions Secrets，即可在推送后自动发布。

## 当前结论

首版不是通用英语学习 App，也不是自由聊天机器人。它服务于有一定词汇基础、但缺少真实输出机会的中文成人；帮助他们在自己的高频工作场景中稳定、清晰地完成表达。

## 非目标（V1）

- 不做儿童独立开放式对话；
- 不自研语音识别或音素级发音评测；
- 不做大而全的教材、词典或泛场景库；
- 不在首版引入人工教师服务。
